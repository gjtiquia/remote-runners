# Triage labels

Label strings match their role names.

Category: bug, enhancement.
State: needs-triage, needs-info, ready-for-agent, ready-for-human,
in-progress, wontfix.
Priority: P0, P1, P2, P3. Default: P2.

Use exactly one category, state, and priority for triaged open issues.
in-progress replaces readiness; do not apply both.
